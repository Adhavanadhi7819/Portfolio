# Adhavan — Game Design Portfolio

A self-contained, responsive portfolio site built from the uploaded `Portfolio.mp4` walkthrough. The included video is optimized to 1280×720 for easier sharing; the selected stills are extracted from that same video.

## Preview locally

1. Keep `index.html` and the `media/` folder together.
2. Open `index.html` in a modern browser.
3. The full portfolio walkthrough is playable in the Reel section.

## Publish

Upload the entire folder to a static host (for example, GitHub Pages, Netlify, or any web host). Keep the `media/` paths unchanged. If uploading via a host with file-size limits, host `media/portfolio-reel.mp4` as a separate asset and update its source path in `index.html`.

## Before sharing publicly

- Replace the contact placeholder in the Contact section with a public email or profile link.
- Confirm your project names, exact responsibilities, and preferred professional title.
- If needed, replace the extracted stills with full-resolution game screenshots.

No external libraries, fonts, or network assets are required.
